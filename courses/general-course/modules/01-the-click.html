What Happens When You Click "Generate"

Ten seconds, five pieces of code, one message traveling there and back.

What This App Even Is

You pick a photo of yourself, hit Generate, watch a spinner for about ten seconds, and a cartoon version of you appears in the Charlie & Lola style. Those ten seconds are basically this whole course, running in miniature — let's slow them down.

Under the hood this is a full commercial product — payments, accounts, two languages, an AI model — packed into roughly 330 TypeScript files. That's more machinery than it looks like from the outside.

The Envelope You Never See Behind

Picture a one-hour photo lab. You slide your film into a paper envelope, write "matte finish, 4x6" on the outside, and post it through a slot in the wall. You never see what happens back there.

1
You write your options on the envelope

Your photo, plus the finish and size you want.

2
You push it through the slot in the wall

It leaves your hands entirely.

3
The back room develops it

You cannot see this part happening — you just wait.

4
An envelope of prints comes back out

The finished result, handed back to you.

Your browser and the server are two separate computers that can only pass each other messages — nothing more. Everything an app does is really just: package a message, send it, wait, unpack the reply.

In this app: the envelope is your request; the slot is the API endpoint; the back room is the server; and the prints coming back are the response.

💡
Key Insight

The entire internet is just this loop, over and over: package a message, send it, wait, unpack the reply. Once you can see that loop, nothing on the internet is actually mysterious — just message after message.

The Envelope

When you click Generate, the browser doesn't send your photo file all by itself — it builds a FormData package first: your photo, plus every option you picked.

The photo itself started life as a giant base64 text string, sitting quietly in memory and localStorage the moment you dropped it in — long before you ever clicked Generate.

This whole exchange is powered by a single JavaScript command called fetch. Here's the actual code that packs and sends the envelope:

CODE 

      const formData = new FormData();

      formData.append('mode', 'image2image');
      formData.append('style', 'charlie-lola'); // Fixed style for Charlie and Lola
      formData.append('aspectRatio', aspectRatio);
      formData.append('outputFormat', outputFormat);
      formData.append('model', 'standard'); // Fixed model

      if (customPrompt.trim()) {
        formData.append('customPrompt', customPrompt);
      }

      for (let i = 0; i < uploadedImages.length; i++) {
        const response = await fetch(uploadedImages[i]);
        const blob = await response.blob();
        formData.append(`image_${i}`, blob);
      }

      formData.append('imageCount', uploadedImages.length.toString());

      const apiResponse = await fetch('/api/generate-cyberpunk', {
        method: 'POST',
        body: formData,
      });

If you typed a custom instruction, tuck that in too.

Write down how many photos are inside.

Push the whole envelope through the slot in the wall — a POST request to /api/generate-cyberpunk.

The Back Room

Behind the slot, code called an API route unpacks your envelope and validates it before doing anything expensive: valid aspect ratio? a photo actually attached? each under 10 MB? enough credits, if you're signed in? a free AI key available right now?

CODE 

export async function POST(request: Request) {
  try {
    const formData = await request.formData();
    const style = formData.get('style') as string || 'charlie-lola';

    const outputFormat = formData.get('outputFormat') as string || 'png';
    const model = formData.get('model') as string || 'standard';
    const imageCount = parseInt(formData.get('imageCount') as string || '0');

Tucked inside that prompt is a whole paragraph of do-nots: "No realistic shading, no detailed rendering, no anime or manga style, no 3D modeling, no photographic textures!" It's just text in a file — anyone who can edit that string can change the entire product.

The Prints Come Back

Gemini's answer arrives as raw image bytes, not a link. So the server uploads it, then packages the whole result as one JSON object.

CODE 

    return respData({

PLAIN ENGLISH

Package the final reply as one object.

imageUrl is where your cartoon actually lives now.

message and provider are just friendly labels about what happened.

creditsUsed says how many credits this cost — zero if you weren't signed in.

requiresRegistration and downloadUrl are the fields that decide whether you see a Sign In button or a working Download button.

PLAIN ENGLISH

Read the server's reply and unpack the JSON.

If the reply says code 0 and there's an imageUrl, save that URL into this component's state — the picture appears immediately.

If you're not signed in, a toast reminds you that signing in unlocks the full download.

Otherwise, if the service is busy, a different toast tells you you're in a queue.

Otherwise, celebrate: show a success toast and refresh your credit balance.

That JSON became React state the instant it arrived — that single change is what makes the picture appear and the toast slide in.
